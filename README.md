## 🛠 3. 트러블 슈팅 (Troubleshooting)
*(본인이 마주친 문제와 해결 과정을 구체적으로 적으세요.)*

### 🚨 문제 상황 (Issue)
- 대량의 데이터를 리스트 형식으로 렌더링할 때, 브라우저에 심각한 버벅임(프레임 드랍) 현상 발생.

### 💡 원인 추론
- 1,000개 이상의 DOM 노드가 한 번에 그려지면서 렌더링 비용이 기하급수적으로 증가함.

### 🎯 해결 방법 (Solution)
- **가상화(Virtualization) 도입:** 화면에 보이는 영역(Viewport)의 리스트만 렌더링하는 `react-window` 라이브러리를 도입하여 DOM 노드 수를 20개 이하로 유지.
- **결과:** 스크롤 시 프레임 속도를 15fps -> 60fps로 개선하여 부드러운 UX 제공.
